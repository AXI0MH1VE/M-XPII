# Security Policy

## Supported Versions

The following versions of Axiom Hive are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our governance systems and software seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not disclose the vulnerability publicly** until we have had a chance to investigate and potentially address it.
2. Send an email to `security@xiipmodelx1.com` with a detailed description of the vulnerability, including steps to reproduce it and a summary of the potential impact.
3. We will acknowledge receipt of your report within 48 hours and provide a timeline for our investigation and response.

Thank you for helping us keep Axiom Hive secure.
