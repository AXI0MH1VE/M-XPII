## 2. On-Page Optimization
GitHub repositories are indexed as web pages. The following optimizations are mandatory:
- **Semantic Headings**: Use H1 for the primary project name and H2/H3 for functional units.
- **Alt Text Invariants**: Every diagram or image file must have descriptive alt text utilizing primary keywords.
- **Meta Descriptions**: The repository tagline must be keyword-rich and under 160 characters.

## 4. Performance Tuning
GitHub Pages performance is optimized via the use of **VitePress**.
- **Static Generation**: Minimize JavaScript payload.
- **Image Compression**: All visual assets must be compressed prior to commit.
- **Sitemap Generation**: Automatic creation via GitHub Actions for search engine crawling.

## 5. Linking Strategy
Internal and external links establish authority:
- **Internal**: Cross-linking between README, WIKI, and detailed unit specifications.
- **External**: Backlinks from institutional or partner domains.
